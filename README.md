# 2048 на Python

Учебная групповая работа по Git. Цель игры — получить плитку 2048 на поле 4×4. Стрелки сдвигают плитки, соседние одинаковые числа объединяются, а значение получившейся плитки прибавляется к счёту. После успешного хода на поле появляется новая плитка. После достижения 2048 можно продолжить игру.

## Запуск

Нужен Python 3 с модулем `tkinter`. Откройте терминал в папке проекта и выполните:

```sh
python3 main.py
```

В Windows вместо `python3` можно использовать `py`. Команда `python3 -m tkinter` открывает тестовое окно, если графический модуль доступен. В игре используйте клавиши ↑ ↓ ← → и кнопку «Новая игра».

## Файлы и история Git

- `game.py` — правила игры. Функция `merge_line` обрабатывает один ряд, а `Game.move` использует её для строк и столбцов.
- `main.py` — окно. Нажатие стрелки вызывает `Game.move`, затем интерфейс обновляет поле и счёт.
- `docs/2048-defense.pptx` — презентация с примером хода, схемой веток и сценарием показа.

## Демонстрация на защите

1. Запустите игру и покажите две стартовые плитки и нулевой счёт.
2. Подведите две одинаковые плитки друг к другу и объедините их. Обратите внимание на новую плитку и прирост счёта.
3. Нажмите «Новая игра». Счёт должен вернуться к нулю, на поле снова будут две плитки.
4. Для воспроизводимой проверки правила слияния выполните:

   ```sh
   python3 -c "from game import merge_line; print(merge_line([2, 2, 4, 0]))"
   ```

   Ожидаемый результат — `([4, 4, 0, 0], 4)`. Это результат обработки ряда до появления новой плитки.
5. Покажите граф коммитов и откройте `game.py` в ветке логики, `main.py` в ветке интерфейса и README в ветке сдачи.

## Перенос Git-репозитория

Если проект передан в файле `2048.bundle`, восстановите его вместе с ветками и историей:

```sh
git clone -b main 2048.bundle 2048
cd 2048
git branch feature/game-logic origin/feature/game-logic
git branch feature/tkinter-ui origin/feature/tkinter-ui
git branch docs/submission origin/docs/submission
```

Репозиторий для сдачи — [tenshi206/2048-The-Game-](https://github.com/tenshi206/2048-The-Game-). Для отправки веток нужен доступ на запись. Если вы восстановили проект из файла, замените адрес `origin`:

```sh
git remote set-url origin https://github.com/tenshi206/2048-The-Game-.git
git push -u origin --all
```

Если у локального репозитория ещё нет `origin`, используйте `git remote add origin` с тем же адресом.
